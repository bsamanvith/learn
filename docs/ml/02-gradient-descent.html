Lesson 02 · Stage 1: learning from data

Gradient descent and the delta rule

The algorithm that trains almost every model in modern machine learning, from a two-parameter line to a trillion-parameter language model. It needs only one thing from the model: the slope of the loss.

The idea

You are on a hillside in fog and want to reach the valley floor. You can't see it, but you can feel the slope under your feet. So you step downhill, feel again, and repeat. In symbols, with parameters $\theta$, loss $J$ and step size $\eta$:

Gradient descent
$$\theta_{k+1} = \theta_k - \eta\,\nabla J(\theta_k).$$

$\eta$ (eta) is the learning rate. The rest of this lesson unpacks each symbol, then proves exactly when this converges.

Every frame is a real step $\theta \leftarrow \theta - \eta\nabla J$ on the data from lesson 01's figure. The faint lines are the last few steps; the right panel is the loss on a log scale.

Slope in one dimension

Math detour · the derivative

The derivative answers: if I nudge $w$ by a tiny amount, how much does $J$ change, per unit of nudge?

$$J'(w) = \frac{dJ}{dw} = \lim_{h\to 0}\frac{J(w+h) - J(w)}{h}.$$

Geometrically it is the slope of the tangent line. Near $w$, the function is almost that line: $J(w + h) \approx J(w) + J'(w)\,h$. This first-order approximation is the whole basis of gradient descent.

If $J'(w) < 0$, increasing $w$ lowers the loss, so move right. If $J'(w) > 0$, move left. Either way, move against the sign of the slope, and move further when it is steep:

$$w \leftarrow w - \eta\,J'(w), \qquad \Delta w = -\eta\,J'(w).$$

The dashed line is the tangent; its slope is $J'(w)$. The orange arrow on the axis is the step $-\eta J'(w)$: long where the bowl is steep, shrinking to nothing at the bottom. Press Take a step a few times and watch the steps shrink on their own, with $\eta$ fixed.

Many parameters: the gradient

With several parameters, ask the same question about each one while freezing the others. That is a partial derivative, written with a curly $\partial$. Stack them into a vector and you have the gradient:

$$\nabla J(\theta) = \begin{bmatrix} \partial J/\partial\theta_1 \\ \vdots \\ \partial J/\partial\theta_p \end{bmatrix}, \qquad J(\theta + \mathbf{h}) \approx J(\theta) + \nabla J(\theta)^\top\mathbf{h}.$$

The gradient is perpendicular to the contour lines of $J$ (moving along a contour doesn't change $J$, so $\nabla J^\top\mathbf{h} = 0$ for such moves) and points in the direction of fastest increase. The next section proves that.

Why minus the gradient is steepest

Take a unit direction $\mathbf{u}$ ($\lVert\mathbf{u}\rVert = 1$). The rate of change of $J$ along $\mathbf{u}$ is the directional derivative $D_{\mathbf{u}}J = \nabla J^\top\mathbf{u}$. By the Cauchy–Schwarz inequality,

$$-\lVert\nabla J\rVert \;\le\; \nabla J^\top\mathbf{u} \;\le\; \lVert\nabla J\rVert,$$

with the lower bound reached exactly at $\mathbf{u} = -\nabla J/\lVert\nabla J\rVert$. So among all directions, minus the gradient decreases $J$ fastest, at rate $\lVert\nabla J\rVert$. And for small enough $\eta$, a step strictly lowers the loss: $J(\theta - \eta\nabla J) \approx J(\theta) - \eta\lVert\nabla J\rVert^2 < J(\theta)$.

"Steepest" depends on how you measure distance. Using the ordinary Euclidean length gives plain gradient descent; other choices give Newton's method and natural gradient, which you will meet later.

The gradient of the squared error

For linear regression $J(w, b) = \frac1n\sum_i r_i^2$ with residual $r_i = w x_i + b - y_i$.

Math detour · the chain rule

If $J$ depends on $r$ and $r$ depends on $w$, then $\dfrac{\partial J}{\partial w} = \dfrac{\partial J}{\partial r}\cdot\dfrac{\partial r}{\partial w}$: "how fast $J$ moves per unit of $r$" times "how fast $r$ moves per unit of $w$". Applied repeatedly through many layers, this one rule is backpropagation (lesson 11).

Here $\partial(r_i^2)/\partial r_i = 2r_i$, $\partial r_i/\partial w = x_i$ and $\partial r_i/\partial b = 1$, so

$$\frac{\partial J}{\partial w} = \frac{2}{n}\sum_{i=1}^n r_i\,x_i, \qquad \frac{\partial J}{\partial b} = \frac{2}{n}\sum_{i=1}^n r_i .$$

In matrix form, with the bias absorbed into $X$ as in lesson 01, this is the gradient we set to zero there:

$$\nabla J(\mathbf{w}) = \frac{2}{n}\,X^\top\!\left(X\mathbf{w} - \mathbf{y}\right).$$

The delta rule

Substitute into the update and write the error as truth minus guess, $\delta_i = y_i - \hat y_i$ (the delta):

The delta rule (Widrow–Hoff, 1960)
$$\Delta w = \eta\,\frac{2}{n}\sum_{i=1}^n \delta_i\,x_i, \qquad \Delta b = \eta\,\frac{2}{n}\sum_{i=1}^n \delta_i .$$

In words: change each weight in proportion to the error times the input attached to that weight. It matches common sense row by row:

Situation$\delta$$x$$\Delta w$Effect
Guess too low, positive input+++raise $w$, guess rises
Guess too low, negative input+−−lower $w$, so $wx$ rises
Guess too high, positive input−+−lower $w$

The last row is the deep idea: each weight is blamed in proportion to how much it contributed to the output. Using one example at a time instead of the average gives the stochastic form $w \leftarrow w + \eta\,\delta_i x_i$, the LMS algorithm that ran in 1960s adaptive filters, and the ancestor of SGD (lesson 08). Lesson 03 will show logistic regression produces the same rule, and in a neural network each neuron gets its own $\delta$, passed backwards through the layers.

The learning rate, analysed

For squared error we can say exactly what happens, because $J$ is quadratic. Let $H = \nabla^2 J = \frac2n X^\top X$ and let $\mathbf{w}^*$ be the minimiser, so $\nabla J(\mathbf{w}) = H(\mathbf{w} - \mathbf{w}^*)$. Track the error $\mathbf{e}_k = \mathbf{w}_k - \mathbf{w}^*$:

$$\mathbf{e}_{k+1} = \mathbf{e}_k - \eta H\mathbf{e}_k = (I - \eta H)\,\mathbf{e}_k \quad\Longrightarrow\quad \mathbf{e}_k = (I - \eta H)^k\,\mathbf{e}_0 .$$

$H$ is symmetric, so it has orthogonal eigenvectors $\mathbf{q}_j$ with eigenvalues $\lambda_j \ge 0$, the curvatures of the bowl along those axes. Along each axis, every step multiplies the error by the same factor:

$$e^{(j)}_{k} = \left(1 - \eta\lambda_j\right)^k e^{(j)}_0 .$$

That single factor explains every behaviour in the figure below:

  • $0 < \eta\lambda < 1$: factor in $(0, 1)$. Smooth, monotone approach. Too small $\eta$ means a factor near 1: very slow.
  • $\eta\lambda = 1$: factor 0. That direction is solved in one step.
  • $1 < \eta\lambda < 2$: factor in $(-1, 0)$. It overshoots, flipping sides each step, but each jump is shorter. A zig-zag that converges.
  • $\eta\lambda > 2$: factor below $-1$. Each jump is longer than the last. Divergence.
Stability condition
$$\text{gradient descent on a quadratic converges} \iff 0 < \eta < \frac{2}{\lambda_{\max}} .$$

Only the slope learns here (the intercept is held at its best value), so the bowl is one-dimensional with curvature $\lambda = 2\,\overline{x^2}$. Each lane uses a different $\eta\lambda$. Underneath, the line that each ball's $w$ draws on the data.

Conditioning and feature scaling

With several directions, one $\eta$ must serve them all. Stability is set by the steepest direction, $\eta < 2/\lambda_{\max}$, but progress along the flattest direction goes at rate $1 - \eta\lambda_{\min}$. The best fixed step, $\eta = 2/(\lambda_{\max} + \lambda_{\min})$, gives the error contraction per step

$$\max_j\,\lvert 1 - \eta\lambda_j\rvert = \frac{\kappa - 1}{\kappa + 1}, \qquad \kappa = \frac{\lambda_{\max}}{\lambda_{\min}} .$$

$\kappa$ is the condition number. A round bowl ($\kappa \approx 1$) is solved in a handful of steps. A long narrow valley ($\kappa \gg 1$) needs on the order of $\kappa$ steps, while the iterates zig-zag across the valley.

For linear regression $H \propto X^\top X$, so $\kappa$ comes from the inputs. Inputs far from zero, or on very different scales, make $X^\top X$ badly conditioned. The fix is to standardise each feature, $x \leftarrow (x - \bar x)/s_x$, before training. In the gradient descent lab, switch the data to "raw x": inputs between 2 and 4 instead of −1 and 1 push $\kappa$ to about 300, and you can watch the walk crawl.

This is why every ML pipeline normalises its inputs, and why deep nets use batch and layer normalisation: they keep the effective $\kappa$ of each layer under control.

Stopping, convexity, and what comes next

  • When to stop: when $\lVert\nabla J\rVert$ falls below a tolerance, when the loss stops improving, or after a fixed budget of steps. In practice, the last one plus a validation check (lesson 04).
  • Convex losses, like squared error on a linear model, have one basin, so gradient descent with a safe $\eta$ finds the global minimum from any start.
  • Neural nets are not convex. They have saddle points, plateaus and many minima. Gradient descent still works remarkably well on them, especially with the noise of mini-batches.
  • Coming up: stochastic and mini-batch gradients, momentum and Adam (lesson 08) all modify the same update to cope with noise and bad conditioning.

Code from scratch

import numpy as np

x = np.array([1.0, 2.0, 3.0])
y = np.array([2.0, 4.0, 5.0])

def loss(w, b):
    return np.mean((w * x + b - y) ** 2)

def grad(w, b):
    r = w * x + b - y                    # residuals: guess minus truth
    return 2 * np.mean(r * x), 2 * np.mean(r)

# The largest stable learning rate is 2 / (largest eigenvalue of the Hessian).
H = 2 * np.array([[np.mean(x * x), np.mean(x)], [np.mean(x), 1.0]])
print("max stable eta:", 2 / np.linalg.eigvalsh(H).max())   # ~0.18

w, b, eta = 0.0, 0.0, 0.1
for step in range(200):
    gw, gb = grad(w, b)
    w, b = w - eta * gw, b - eta * gb    # the update
print(w, b, loss(w, b))                  # 1.5 0.667 0.0556

The full script, with a numerical gradient check and a divergence demo, is books/machine-learning/02-gradient-descent/code/gradient_descent.py in the repo.

Exercises

  1. For $J(w) = (w-3)^2$, starting at $w = 0$ with $\eta = 0.25$, do three steps by hand. What fraction of the remaining distance does each step close?
  2. Same function with $\eta = 1.1$. Do three steps. Why does it diverge?
  3. Check numerically that $\frac{\partial J}{\partial w} \approx \frac{J(w+h) - J(w)}{h}$ at $w = b = 0$ for the worked example, with $h = 10^{-5}$.
  4. Prove that for $J(\theta) = \frac12\theta^\top A\theta$ with $A$ symmetric positive definite, gradient descent converges if and only if $0 < \eta < 2/\lambda_{\max}(A)$.
  5. Show that $\eta = 2/(\lambda_{\max} + \lambda_{\min})$ minimises $\max_j \lvert 1 - \eta\lambda_j\rvert$, and that the minimum equals $(\kappa - 1)/(\kappa + 1)$.
  6. For one input, the Hessian of the MSE is $2\begin{bmatrix}\overline{x^2} & \bar x\\ \bar x & 1\end{bmatrix}$. Show that centring the inputs ($\bar x = 0$) makes it diagonal. What is $\kappa$ then?
  7. Replace the full gradient with the gradient of one random example per step. Plot the loss. Why does it never settle exactly with a fixed $\eta$?
Answers

1. $J'(w) = 2(w-3)$. Iterates $0 \to 1.5 \to 2.25 \to 2.625$. Each step multiplies the distance to 3 by $1 - \eta\lambda = 1 - 0.25\cdot 2 = 0.5$.

2. $0 \to 6.6 \to -1.32 \to 8.18$. The factor is $1 - 1.1\cdot 2 = -1.2$: the sign flips and the distance grows 20% per step, because $\eta = 1.1 > 2/\lambda = 1$.

3. The analytic values are $-16.667$ and $-7.333$; the forward difference agrees to about 5 digits.

4. $\nabla J = A\theta$, so $\theta_k = (I - \eta A)^k\theta_0$. In the eigenbasis each coordinate is multiplied by $(1 - \eta\lambda_j)^k$, which tends to 0 for every start if and only if $\lvert 1 - \eta\lambda_j\rvert < 1$ for all $j$, that is $0 < \eta\lambda_j < 2$. The binding constraint is $\lambda_{\max}$.

5. $\max_j\lvert 1 - \eta\lambda_j\rvert = \max(\lvert 1 - \eta\lambda_{\min}\rvert, \lvert 1 - \eta\lambda_{\max}\rvert)$. The first falls and the second rises with $\eta$, so the max is smallest where $1 - \eta\lambda_{\min} = \eta\lambda_{\max} - 1$, giving $\eta = 2/(\lambda_{\max} + \lambda_{\min})$ and value $(\lambda_{\max} - \lambda_{\min})/(\lambda_{\max} + \lambda_{\min}) = (\kappa-1)/(\kappa+1)$.

6. With $\bar x = 0$ the off-diagonal entries vanish, leaving eigenvalues $2\overline{x^2}$ and $2$. So $\kappa = \max(\overline{x^2}, 1)/\min(\overline{x^2}, 1)$, which is 1 if you also scale $x$ to unit variance.

7. Each single-example gradient is a noisy estimate of the full gradient. At the minimum the full gradient is zero but the single-example gradients are not, so with a fixed $\eta$ the iterates keep jittering in a small region. Shrinking $\eta$ over time removes the jitter.
