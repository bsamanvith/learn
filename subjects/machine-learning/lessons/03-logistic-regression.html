Lesson 03 · Stage 1: learning from data

Logistic regression and log-loss

Turn a line into a probability, score it by how surprised it is by the truth, and train it with gradient descent. The loss you meet here, cross-entropy, is the same one that trains every classifier network and every large language model.

Prerequisites: 01 and 02Math pulled in: exponentials and logarithms, odds, the Bernoulli distribution, likelihood, cross-entropy, positive semidefinite matrices

From numbers to yes or no

Now each label is binary: $y_i \in \{0, 1\}$. Did a student pass, given hours studied? Is an email spam? We want the model to output a probability $p = P(y = 1 \mid \mathbf{x})$, a number in $[0, 1]$.

Linear regression is a poor fit. Its output $\mathbf{w}^\top\mathbf{x} + b$ is unbounded, so it predicts "probabilities" like 1.4 and −0.3. And squared error treats a confident correct answer far from the boundary as an error to be fixed, so a few easy examples can drag the boundary off course. We keep the line, and change what we do with it.

The sigmoid

Compute a score $z = \mathbf{w}^\top\mathbf{x} + b$, called the logit, then squash it into $(0, 1)$ with the logistic sigmoid:

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad p = \sigma(\mathbf{w}^\top\mathbf{x} + b).$$

Properties used constantly:

  • $\sigma(0) = \tfrac12$, $\sigma(z) \to 1$ as $z \to \infty$, $\sigma(z) \to 0$ as $z \to -\infty$.
  • Symmetry: $\sigma(-z) = 1 - \sigma(z)$.
  • Derivative: $\sigma'(z) = \sigma(z)\big(1 - \sigma(z)\big)$, largest (¼) at $z = 0$ and nearly zero in the tails.

The decision boundary, where $p = \tfrac12$, is where the logit is zero: $\mathbf{w}^\top\mathbf{x} + b = 0$, a hyperplane. With one input, $x = -b/w$. So logistic regression is still a linear classifier: the boundary is flat, only the probabilities curve.

The faint dashed line is the logit $z = wx + b$ (scaled to fit); the orange curve is $\sigma(z)$. $w$ sets how sharp the S is and which way it faces; $b$ slides it. Set $w$ to 0 and the model can only say one probability everywhere.

The model reads as log-odds

Math detour · odds and logarithms

The odds of an event with probability $p$ are $p/(1-p)$: $p = 0.8$ is odds of 4 to 1. The natural log undoes $e^x$, and turns products into sums: $\log(ab) = \log a + \log b$. Logs of numbers near 0 are large and negative ($\log 0.01 \approx -4.6$).

Invert the sigmoid and the model becomes a statement about odds:

$$\log\frac{p}{1 - p} = \mathbf{w}^\top\mathbf{x} + b .$$

So logistic regression says the log-odds are linear in the inputs. Each unit increase in $x_j$ adds $w_j$ to the log-odds, which multiplies the odds by $e^{w_j}$. This is why the coefficients are interpretable in medicine and social science: $w = 0.7$ means "each extra unit roughly doubles the odds" ($e^{0.7} \approx 2.01$).

Maximum likelihood gives log-loss

Follow the recipe from lesson 01: choose a noise model, write the likelihood, take $-\log$.

Math detour · Bernoulli

A yes/no outcome with $P(y = 1) = p$ is a Bernoulli variable. Its probability mass function, in one line, is $P(y) = p^{\,y}(1 - p)^{1 - y}$: it equals $p$ when $y = 1$ and $1 - p$ when $y = 0$.

With independent examples and $p_i = \sigma(\mathbf{w}^\top\mathbf{x}_i + b)$, the likelihood and its negative average log are

$$\mathcal{L}(\mathbf{w}) = \prod_{i=1}^n p_i^{\,y_i}(1 - p_i)^{1 - y_i}, \qquad J(\mathbf{w}) = -\frac1n\sum_{i=1}^n\Big[\,y_i\log p_i + (1 - y_i)\log(1 - p_i)\Big].$$

This is log-loss, or binary cross-entropy. Only one term is active per example: $-\log p_i$ if the truth is 1, $-\log(1 - p_i)$ if it is 0.

Slide $p$ toward the wrong end. The cost of a confident mistake grows without bound ($-\log 0.01 \approx 4.6$), while a confident correct answer costs almost nothing. A model trained this way learns to be honest about its uncertainty.

Cross-entropy: the information view

The same formula has a second meaning. For a true distribution $q$ and a model distribution $p$ over outcomes, the cross-entropy is

$$H(q, p) = -\sum_{\text{outcomes } k} q_k \log p_k = H(q) + D_{\mathrm{KL}}(q \,\Vert\, p).$$

It is the average number of nats needed to encode outcomes drawn from $q$ using a code built for $p$. For one example the true distribution puts all its mass on $y_i$, so $H(q) = 0$, and the cross-entropy is exactly the log-loss term. Minimising log-loss is minimising the KL divergence from the labels to the model. With $K$ classes and a softmax instead of a sigmoid, this is the loss of every classifier network and of next-token prediction in LLMs (lesson 07).

The gradient: the delta rule again

Chain rule through $z_i = \mathbf{w}^\top\mathbf{x}_i + b$ and $p_i = \sigma(z_i)$, for one example's loss $\ell_i$:

$$\frac{\partial \ell_i}{\partial p_i} = -\frac{y_i}{p_i} + \frac{1 - y_i}{1 - p_i} = \frac{p_i - y_i}{p_i(1 - p_i)}, \qquad \frac{\partial p_i}{\partial z_i} = p_i(1 - p_i).$$

Multiply them, and everything messy cancels:

$$\frac{\partial \ell_i}{\partial z_i} = p_i - y_i .$$

With $\partial z_i/\partial\mathbf{w} = \mathbf{x}_i$ and $\partial z_i/\partial b = 1$:

Gradient of log-loss
$$\nabla_{\mathbf{w}} J = \frac1n\sum_{i=1}^n (p_i - y_i)\,\mathbf{x}_i = \frac1n X^\top(\mathbf{p} - \mathbf{y}), \qquad \frac{\partial J}{\partial b} = \frac1n\sum_{i=1}^n (p_i - y_i).$$

Compare with lesson 02: it is the delta rule, error times input, with the prediction now a probability. This is no coincidence. Squared error with a linear output, log-loss with a sigmoid, and cross-entropy with a softmax are each the canonical pairing for their output (they come from exponential-family likelihoods), and for every canonical pair the gradient at the logit is simply prediction minus truth (up to a constant factor). Backpropagation in a classifier network starts from exactly this $\mathbf{p} - \mathbf{y}$.

Convexity, and why not squared error

Differentiate once more. Using $\partial p_i/\partial z_i = p_i(1 - p_i)$:

$$\nabla^2 J = \frac1n\sum_{i=1}^n p_i(1 - p_i)\,\mathbf{x}_i\mathbf{x}_i^\top = \frac1n X^\top S X, \qquad S = \operatorname{diag}\big(p_i(1 - p_i)\big).$$

Every weight $p_i(1-p_i)$ is positive, so $\mathbf{v}^\top X^\top S X\mathbf{v} = \sum_i p_i(1-p_i)(\mathbf{x}_i^\top\mathbf{v})^2 \ge 0$. The Hessian is positive semidefinite and log-loss is convex: gradient descent cannot get stuck in a false minimum.

Now try squared error on the probability, $\frac1n\sum_i(p_i - y_i)^2$. Its gradient at the logit is $2(p_i - y_i)\,p_i(1 - p_i)$. When the model is confidently wrong ($p_i \approx 0$ but $y_i = 1$), the factor $p_i(1-p_i)$ is nearly zero, so the gradient vanishes exactly when learning should be fastest. The loss surface also stops being convex. The logarithm in log-loss cancels the sigmoid's flat tails; that is why the pairing matters.

Training it

Set the gradient to zero and you get $X^\top(\sigma(X\mathbf{w}) - \mathbf{y}) = \mathbf{0}$, which is nonlinear in $\mathbf{w}$: no closed form exists. So we iterate. Plain gradient descent works; the classical alternative is Newton's method, $\mathbf{w} \leftarrow \mathbf{w} - (X^\top S X)^{-1}X^\top(\mathbf{p} - \mathbf{y})$, which statisticians call iteratively reweighted least squares. It converges in a handful of steps but needs a $d \times d$ solve each time.

Gradient descent on log-loss, starting from $w = b = 0$ (a flat $p = 0.5$). Passes are on the top row, fails on the bottom. The thin lines are each example's $p_i - y_i$, the delta that drives the update. The curve never becomes a perfect step, because a few students near the middle went the "wrong" way, and log-loss prefers honest uncertainty to confident mistakes.

Separable data and exploding weights

If a hyperplane separates the classes perfectly, scaling $\mathbf{w}$ and $b$ up by any factor $c > 1$ pushes every $p_i$ closer to its label and lowers the loss further. The infimum is 0 and is never reached: the MLE does not exist, and gradient descent sends $\lVert\mathbf{w}\rVert \to \infty$, slowly. (The direction of $\mathbf{w}$ does converge, to the maximum-margin separator, a result with real consequences for deep nets.)

The practical fix is regularisation: minimise $J(\mathbf{w}) + \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2$, which keeps the weights finite and the probabilities calibrated (lesson 05).

Code from scratch

import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0])   # hours studied
y = np.array([0.0, 0.0, 1.0, 1.0])   # passed?
X = np.column_stack([x, np.ones_like(x)])

def sigmoid(z):
  return 1 / (1 + np.exp(-z))

def log_loss(w):
  p = np.clip(sigmoid(X @ w), 1e-12, 1 - 1e-12)   # avoid log(0)
  return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

def grad(w):
  return X.T @ (sigmoid(X @ w) - y) / len(y)      # (1/n) X^T (p - y)

w = np.zeros(2)
for step in range(5000):
  w -= 0.5 * grad(w)
print(w, log_loss(w))   # w keeps growing: this data is separable

Exercises

Data: hours $x = (0, 1, 2, 3)$, passed $y = (0, 0, 1, 1)$.

  1. Compute $\sigma(-2)$, $\sigma(0)$ and $\sigma(2)$.
  2. For $w = 2$, $b = -3$, compute each $p_i$, the decision boundary, and the log-loss.
  3. At that $(w, b)$, compute $\partial J/\partial w$ and $\partial J/\partial b$. Which way should each move?
  4. Prove $\sigma'(z) = \sigma(z)(1 - \sigma(z))$ and $\sigma(-z) = 1 - \sigma(z)$.
  5. Derive the Hessian $\frac1n X^\top S X$ and show it is positive semidefinite.
  6. Show that for separable data the loss has no minimiser. What does gradient descent do?
  7. With labels in $\{-1, +1\}$ instead of $\{0, 1\}$, show the log-loss can be written $\frac1n\sum_i \log\!\left(1 + e^{-y_i(\mathbf{w}^\top\mathbf{x}_i + b)}\right)$.
Answers

1. $\sigma(-2) \approx 0.119$, $\sigma(0) = 0.5$, $\sigma(2) \approx 0.881$.

2. $z = -3, -1, 1, 3$ so $p \approx 0.047, 0.269, 0.731, 0.953$. Boundary at $x = 1.5$. Costs $\approx 0.049, 0.313, 0.313, 0.049$, mean $\approx 0.181$.

3. $p - y \approx 0.047, 0.269, -0.269, -0.047$. $\partial J/\partial b = 0$ by symmetry and $\partial J/\partial w = \tfrac14(0 + 0.269 - 0.538 - 0.142) \approx -0.103$. So $w$ should grow (a sharper S) and $b$ is balanced for this $w$.

4. $\sigma = (1 + e^{-z})^{-1}$, so $\sigma' = e^{-z}(1 + e^{-z})^{-2} = \sigma\cdot\frac{e^{-z}}{1 + e^{-z}} = \sigma(1 - \sigma)$. And $1 - \sigma(z) = \frac{e^{-z}}{1 + e^{-z}} = \frac{1}{e^{z} + 1} = \sigma(-z)$.

5. $\nabla J = \frac1n\sum_i (p_i - y_i)\mathbf{x}_i$; differentiating $p_i$ gives $p_i(1-p_i)\mathbf{x}_i^\top$, so $\nabla^2 J = \frac1n\sum_i p_i(1-p_i)\mathbf{x}_i\mathbf{x}_i^\top$. For any $\mathbf{v}$, $\mathbf{v}^\top\nabla^2 J\,\mathbf{v} = \frac1n\sum_i p_i(1 - p_i)(\mathbf{x}_i^\top\mathbf{v})^2 \ge 0$.

6. If $(\mathbf{w}, b)$ separates the data, every $z_i$ has the sign of its label, and $J(c\mathbf{w}, cb)$ strictly decreases toward 0 as $c \to \infty$, yet every term stays positive, so no finite point attains the infimum. Gradient descent keeps increasing $\lVert\mathbf{w}\rVert$ roughly logarithmically in the number of steps.

7. For $y = +1$ the term is $-\log\sigma(z) = \log(1 + e^{-z})$. For $y = -1$ (old label 0) it is $-\log(1 - \sigma(z)) = -\log\sigma(-z) = \log(1 + e^{z})$. Both are $\log(1 + e^{-yz})$.
