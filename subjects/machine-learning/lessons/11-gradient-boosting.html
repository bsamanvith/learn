Lesson 11 · Stage 3: trees and boosting

Gradient boosting

Random forests average many deep trees grown independently. Boosting builds shallow trees one at a time, each one correcting the mistakes of the ensemble so far. Done right, "correcting the mistakes" turns out to mean "taking a gradient descent step in the space of functions". This lesson derives that view, then the second-order version used by XGBoost and LightGBM, which remain the models to beat on tabular data.

Prerequisites: lesson 02, lesson 03, lesson 09Math pulled in: additive models, functional gradients, second-order Taylor expansion, Newton steps, regularised leaf weights

The idea

Fit a small regression tree to the data. It will be wrong in places. Compute the residuals $r_i = y_i - F(\mathbf{x}_i)$, fit a second small tree to the residuals, and add a fraction of it to the model. Repeat. After $M$ rounds the model is a sum

$$F_M(\mathbf{x}) = F_0 + \nu\sum_{m=1}^{M}f_m(\mathbf{x}),$$

where every $f_m$ is a small tree and $\nu\in(0, 1]$ is a learning rate (or shrinkage). No tree is a good model on its own; each is a small correction.

Left: boosting depth-1 trees ("stumps") on noisy samples of a sine curve with squared loss and $\nu = 0.3$. After 1 round the model is a single step; after 10 it has the rough shape; after 100 it follows the curve closely and starts chasing noise. Right: test log-loss of the code's classifier on lesson 10's problem, for 1,500 rounds. With $\nu = 1$ the best test loss (0.449) comes after 17 trees and then it overfits badly; with $\nu = 0.1$ it reaches 0.421 after 333 trees and degrades much more slowly.

Boosting is gradient descent on functions

Why residuals? For the squared loss $\ell(y, F) = \tfrac12(y - F)^2$, the residual is the negative gradient of the loss with respect to the prediction: $-\partial\ell/\partial F = y - F$. That suggests the general recipe. Treat the $n$ predictions $F(\mathbf{x}_1),\dots,F(\mathbf{x}_n)$ as the parameters, and take a gradient step on the training loss $\sum_i\ell(y_i, F(\mathbf{x}_i))$. The gradient has one entry per training point:

$$g_i = \frac{\partial\ell(y_i, F)}{\partial F}\bigg|_{F = F_{m-1}(\mathbf{x}_i)} .$$

Moving the predictions to $F(\mathbf{x}_i) - \nu g_i$ would lower the training loss, but it only defines the model at training points and would memorise them. So instead we fit a regression tree $f_m$ to the targets $-g_i$, the pseudo-residuals, by least squares. The tree is the closest function in the family of small trees to the negative gradient, so it generalises the step to inputs we haven't seen. Then $F_m = F_{m-1} + \nu f_m$. This is gradient boosting (Friedman, 2001).

For classification $F$ is a log-odds (or a vector of logits), not a probability, so the sum of trees can take any real value and the sigmoid turns it into a probability at the end. $F_0$ is the best constant: the mean for squared loss, the log-odds of the base rate for log-loss.

Second order: the XGBoost objective

Fitting the tree to $-g_i$ by least squares uses only the slope of the loss. Using the curvature too gives better trees and better leaf values. Write $h_i = \partial^2\ell/\partial F^2$ at the current prediction, and expand the loss of adding a new tree $f$ to second order (lesson 02's Taylor expansion):

$$\sum_i\ell\big(y_i, F_i + f(\mathbf{x}_i)\big)\approx\sum_i\Big[\ell(y_i, F_i) + g_if(\mathbf{x}_i) + \tfrac12h_if(\mathbf{x}_i)^2\Big].$$

A tree with $T$ leaves assigns the value $w_j$ to every point in leaf $j$. Add a penalty $\Omega(f) = \gamma T + \tfrac\lambda2\sum_jw_j^2$ (a price per leaf and ridge on the leaf values, lesson 05). Dropping the constant and grouping points by leaf, with $G_j = \sum_{i\in\text{leaf }j}g_i$ and $H_j = \sum_{i\in\text{leaf }j}h_i$:

$$\text{obj}(f) = \sum_{j=1}^T\Big[G_jw_j + \tfrac12(H_j + \lambda)\,w_j^2\Big] + \gamma T .$$

Each leaf's term is a one-dimensional quadratic, minimised at

Optimal leaf value and the score of a tree
$$w_j^* = -\frac{G_j}{H_j + \lambda}, \qquad \text{obj}^* = -\frac12\sum_{j=1}^T\frac{G_j^2}{H_j + \lambda} + \gamma T .$$

$w_j^*$ is a Newton step (gradient over curvature), damped by $\lambda$. And $\text{obj}^*$ scores any tree structure, so it can choose splits. Splitting a leaf into $L$ and $R$ changes the objective by

Split gain
$$\text{gain} = \frac12\left[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\right] - \gamma .$$

Split only if the gain is positive, which is how $\gamma$ prunes. The search is lesson 09's sorted sweep with running sums of $g$ and $h$ instead of class counts. For squared loss $h_i = 1$, so $H_j$ is the leaf's size and $w_j^*$ is the leaf's mean residual, shrunk toward zero by $\lambda$. For log-loss, $g_i = p_i - y_i$ and $h_i = p_i(1 - p_i)$: points the model is already sure about (tiny $h_i$) count for less. This is the algorithm of XGBoost (Chen & Guestrin, 2016), and the code below implements it in about 40 lines.

Keeping boosting honest

Each round lowers the training loss, so with enough rounds boosting will fit noise. The figure's $\nu = 1$ curve shows how fast that can happen. The standard defences:

  • Shrinkage. Small $\nu$ (0.01–0.1) with many trees generalises better than large $\nu$ with few. Each tree then makes only a small correction, so later trees can undo the mistakes of earlier ones, much like a small step size in gradient descent. Lesson 05 showed that early-stopped gradient descent with small steps behaves like ridge regression; shrinkage plus early stopping plays the same role here.
  • Early stopping. Watch the loss on a validation set and stop when it stops improving (lesson 04).
  • Small trees. A tree of depth $D$ can only express interactions among up to $D$ features. Depths 3–8 are typical. The bias is removed by adding trees, not by growing each one deep.
  • Subsampling. Fit each tree on a random half of the rows and a random subset of the columns ("stochastic gradient boosting"). That adds randomness, as in lesson 10, and makes each round cheaper.
  • $\lambda$, $\gamma$ and a minimum $H$ per leaf, from the objective above.

Boosting and bagging attack different terms. Random forests average low-bias, high-variance trees to cut variance. Boosting adds up high-bias, low-variance trees to cut bias, and needs regularisation to keep variance in check. On lesson 10's problem, the boosted model reaches a test accuracy of 0.815 against the forest's 0.800.

Gradient boosting in practice

The three widely used libraries are refinements of the algorithm above:

  • XGBoost: the second-order objective, sparsity-aware splits for missing values (each split learns a default direction for them), and column subsampling.
  • LightGBM: features are bucketed into at most 255 bins once, before training, so a split search is a sweep over a histogram rather than a sort. Trees grow leaf-wise (always split the leaf with the largest gain) rather than level by level.
  • CatBoost: careful handling of categorical features, and "ordered boosting", which avoids a subtle target leak in how residuals are computed for the points a tree was trained on.

On tables of heterogeneous features (finance, logistics, medicine), well-tuned gradient-boosted trees still match or beat deep networks in most benchmarks (Grinsztajn et al., 2022). Neural networks win when the input has structure that convolution or attention can exploit: images, audio, text. That is the subject of the next three stages.

Code from scratch

import numpy as np

rng = np.random.default_rng(0)
d = 10

def make(n):                                       # the same problem as lesson 10
    X = rng.uniform(-1, 1, (n, d))
    score = X[:, 0] ** 2 + X[:, 1] ** 2 + X[:, 2] * X[:, 3] - 0.6
    p = 1 / (1 + np.exp(-8 * score))
    return X, (rng.random(n) < p).astype(int), p

def build(X, g, h, depth, lam, gamma):
    """A regression tree fitted to gradients g and Hessians h with the second-order gain.
    Leaves store the Newton step w* = -G / (H + lam)."""
    G, H = g.sum(), h.sum()
    leaf = -G / (H + lam)
    if depth == 0 or len(g) < 2:
        return leaf
    best_gain, best = 0.0, None
    for j in range(X.shape[1]):
        o = np.argsort(X[:, j]); xs = X[o, j]
        GL, HL = np.cumsum(g[o])[:-1], np.cumsum(h[o])[:-1]
        gain = 0.5 * (GL**2 / (HL + lam) + (G - GL)**2 / (H - HL + lam) - G**2 / (H + lam)) - gamma
        gain[xs[1:] == xs[:-1]] = -np.inf
        i = np.argmax(gain)
        if gain[i] > best_gain:
            best_gain, best = gain[i], (j, (xs[i] + xs[i + 1]) / 2)
    if best is None:
        return leaf
    j, t = best; m = X[:, j] <= t
    return (j, t, build(X[m], g[m], h[m], depth - 1, lam, gamma), build(X[~m], g[~m], h[~m], depth - 1, lam, gamma))

def tree_predict(tree, X):
    if not isinstance(tree, tuple):
        return np.full(len(X), tree)
    j, t, l, r = tree; m = X[:, j] <= t
    out = np.empty(len(X)); out[m], out[~m] = tree_predict(l, X[m]), tree_predict(r, X[~m])
    return out

sigmoid = lambda z: 1 / (1 + np.exp(-z))
logloss = lambda y, F: np.mean(np.logaddexp(0, F) - y * F)

def boost(X, y, rounds, lr=0.1, depth=3, lam=1.0, gamma=0.0):
    F0 = np.log(y.mean() / (1 - y.mean()))        # start from the best constant: the log-odds
    F = np.full(len(y), F0)
    trees = []
    for _ in range(rounds):
        p = sigmoid(F)
        g, h = p - y, p * (1 - p)                  # gradient and Hessian of the log-loss in F
        tree = build(X, g, h, depth, lam, gamma)
        F += lr * tree_predict(tree, X)
        trees.append(tree)
    return F0, trees

def boosted_F(F0, trees, X, lr=0.1, upto=None):
    return F0 + lr * sum(tree_predict(t, X) for t in trees[:upto])

Xtr, ytr, _ = make(500); Xte, yte, pte = make(4000)
F0, trees = boost(Xtr, ytr, rounds=400)
for M in [1, 10, 50, 100, 200, 400]:
    Ftr, Fte = boosted_F(F0, trees, Xtr, upto=M), boosted_F(F0, trees, Xte, upto=M)
    print(f"{M:3d} trees: train log-loss {logloss(ytr, Ftr):.3f}  test log-loss {logloss(yte, Fte):.3f}"
          f"  test acc {np.mean((Fte > 0) == yte):.3f}")
print(f"best possible: test log-loss {logloss(yte, np.log(pte / (1 - pte))):.3f}  test acc {np.mean(np.maximum(pte, 1 - pte)):.3f}")

#   1 trees: train log-loss 0.664  test log-loss 0.670  test acc 0.711
#  10 trees: train log-loss 0.526  test log-loss 0.572  test acc 0.746
#  50 trees: train log-loss 0.311  test log-loss 0.472  test acc 0.778
# 100 trees: train log-loss 0.234  test log-loss 0.464  test acc 0.781
# 200 trees: train log-loss 0.121  test log-loss 0.436  test acc 0.795
# 400 trees: train log-loss 0.040  test log-loss 0.427  test acc 0.815
# best possible: test log-loss 0.265  test acc 0.883

The first tree barely helps: one depth-3 tree is a crude model. After 400 rounds the training loss is near zero while the test loss has settled around 0.43, and the test accuracy (0.815) beats lesson 10's random forest (0.800) on the same data. The gap to the best possible model (log-loss 0.265, accuracy 0.883) is the price of learning from 500 noisy examples.

Exercises

  1. For the squared loss, show that gradient boosting with $\nu = 1$ and trees fitted by least squares is exactly "fit a tree to the residuals, add it, repeat".
  2. Derive $g_i$ and $h_i$ for the log-loss $\ell(y, F) = \log(1 + e^F) - yF$, and show that $w^* = \sum(y_i - p_i)/\big(\sum p_i(1 - p_i) + \lambda\big)$ for a leaf.
  3. A leaf contains points with $g = (0.4, 0.3, -0.2)$ and $h = (0.24, 0.21, 0.16)$. With $\lambda = 1$, what is its value $w^*$, and what does it contribute to obj$^*$?
  4. Show that the split gain with $\lambda = \gamma = 0$ and squared loss reduces to lesson 09's regression formula $\frac{n_Ln_R}{n}(\bar r_L - \bar r_R)^2$ (up to a factor ½), where $\bar r$ is the mean residual.
  5. AdaBoost minimises the exponential loss $\ell(y, F) = e^{-yF}$ with $y\in\{-1, +1\}$. Show that the population minimiser is $F^*(\mathbf{x}) = \tfrac12\log\frac{P(y = 1\mid\mathbf{x})}{P(y = -1\mid\mathbf{x})}$, half the log-odds. Why is the exponential loss less robust to mislabelled points than the log-loss?
  6. Why does a model made of depth-1 trees contain no interactions between features? Write it as a sum of functions of single features.
Answers

1. $-g_i = y_i - F_{m-1}(\mathbf{x}_i)$, the residual. Fitting a tree to it by least squares and adding it with $\nu = 1$ is the residual-fitting loop.

2. $g = \sigma(F) - y = p - y$, $h = \sigma(F)(1 - \sigma(F)) = p(1-p)$. Then $w^* = -G/(H + \lambda) = \sum(y_i - p_i)/(\sum p_i(1-p_i) + \lambda)$: a Newton step on the log-odds.

3. $G = 0.5$, $H = 0.61$. $w^* = -0.5/1.61 = -0.311$; contribution $-\tfrac12\cdot0.25/1.61 = -0.078$.

4. With $h_i = 1$ the gain is $\tfrac12\big[G_L^2/n_L + G_R^2/n_R - G^2/n\big]$, and $G_A = -\sum_{i\in A}r_i = -n_A\bar r_A$. So the bracket is $n_L\bar r_L^2 + n_R\bar r_R^2 - n\bar r^2$, which lesson 09's exercise 3 showed equals $\frac{n_Ln_R}{n}(\bar r_L - \bar r_R)^2$.

5. At a fixed $\mathbf{x}$ with $q = P(y = 1\mid\mathbf{x})$, minimise $qe^{-F} + (1-q)e^{F}$: the derivative is zero at $e^{2F} = q/(1-q)$. The exponential loss of a confidently misclassified point grows like $e^{|F|}$, while the log-loss grows only linearly in $|F|$, so a few mislabelled points can dominate AdaBoost's later rounds.

6. A stump splits on one feature, so $f_m(\mathbf{x}) = \phi_m(x_{j_m})$. Grouping the stumps by feature gives $F(\mathbf{x}) = F_0 + \sum_j\Phi_j(x_j)$, an additive model: no term depends on two features at once. Depth-$D$ trees allow interactions of order up to $D$.
