Lesson 35 · Stage 8: reinforcement learning

Monte Carlo and temporal-difference learning

Dynamic programming needs the model. This lesson learns a policy's values from experience alone, by two routes. Monte Carlo methods wait until an episode ends and average the returns that actually happened. Temporal-difference (TD) methods update after every step, using the current estimate of the next state's value in place of the rest of the return: they bootstrap. The lesson derives TD as a sampled version of the Bellman operator, explains when and why it converges, and proves the striking fact that batch TD computes the exact value of the maximum-likelihood model of the data. It then builds the spectrum in between, $n$-step returns and the $\lambda$-return, and proves that eligibility traces implement the $\lambda$-return incrementally. The code reproduces Sutton and Barto's random-walk experiments.

Prerequisites: 34, 07, M3Math pulled in: unbiased estimators and variance, incremental means, stochastic approximation and the Robbins–Monro conditions, geometric weightings, telescoping sums

The idea

The task in this lesson is prediction: estimate $V^\pi$ for a fixed policy $\pi$ from episodes generated by following it, without knowing $P$ or $R$. (Lesson 36 turns prediction into control.) There are two natural targets for $V(S_t)$:

$$\underbrace{G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2R_{t+3} + \cdots}_{\text{Monte Carlo: the actual return}}\qquad\qquad\underbrace{R_{t+1} + \gamma V(S_{t+1})}_{\text{TD: one real reward, then the estimate}}$$

The first is what $V^\pi(S_t)$ is defined to be the expectation of, so it is an unbiased target, but it depends on every random step to the end of the episode, and it is not available until the episode ends. The second is available after one step and depends on only one transition, but it is built on the current estimate $V$, which may be wrong. This choice, sample the whole future or bootstrap from an estimate after a few steps, is the first of the trade-offs that run through all of RL. The answer, in theory and in practice, is usually somewhere in between.

Monte Carlo prediction

Run episodes with $\pi$; every time state $s$ is visited, record the return that followed; estimate $V(s)$ by the average. First-visit MC uses only the first visit to $s$ in each episode. Those returns are independent and identically distributed with mean $V^\pi(s)$, so the average is unbiased and converges by the law of large numbers, with standard error $\sigma(s)/\sqrt{N(s)}$. Every-visit MC uses all visits; its returns from the same episode are correlated and the estimate is slightly biased for finite samples, but it is also consistent.

Averages can be computed incrementally, as lesson 32 did for bandits: after the $N$-th return $G$ from $s$,

$$V(s)\leftarrow V(s) + \frac{1}{N(s)}\big(G - V(s)\big).$$

Replacing $1/N$ by a constant step size $\alpha$ gives constant-$\alpha$ MC, which computes an exponentially weighted average in which the $k$-th most recent return has weight $\alpha(1 - \alpha)^k$. It never stops fluctuating, but it tracks a target that drifts, which is what happens in control, where the policy, and hence $V^\pi$, keeps changing.

MC's weakness is variance. The return sums many random rewards and transitions, so its variance typically grows with the episode length. And it learns nothing until an episode ends, which is useless for tasks that never end and slow for long ones.

TD(0): sampling the Bellman operator

The TD(0) update, after each transition $(S_t, R_{t+1}, S_{t+1})$, is

$$V(S_t)\leftarrow V(S_t) + \alpha\,\delta_t,\qquad\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t),$$

where $\delta_t$ is the TD error: the difference between what the estimate predicted and the better-informed prediction one step later. Where it comes from: given the current $V$, the conditional expectation of the TD target is exactly the Bellman operator,

$$\mathbb{E}_\pi\big[R_{t+1} + \gamma V(S_{t+1})\mid S_t = s\big] = \sum_a\pi(a\mid s)\Big[R(s, a) + \gamma\sum_{s'}P(s'\mid s, a)V(s')\Big] = (\mathcal{T}^\pi V)(s).$$

So the TD target is an unbiased sample of $\mathcal{T}^\pi V$, and TD(0) is iterative policy evaluation (lesson 34) with the expectation replaced by a single sample, and with a small step towards the target instead of jumping to it. The expected TD error in each state is zero exactly when $\mathcal{T}^\pi V = V$, that is, when $V = V^\pi$.

Convergence. This is a stochastic approximation algorithm in the sense of Robbins and Monro (1951): it seeks a zero of $V\mapsto\mathcal{T}^\pi V - V$ from noisy evaluations of it. If every state is visited infinitely often and the step sizes for each state satisfy

$$\sum_k\alpha_k = \infty,\qquad\sum_k\alpha_k^2 < \infty$$

(for instance $\alpha_k = 1/k$), then tabular TD(0) converges to $V^\pi$ with probability 1 (Sutton 1988; Dayan 1992; Jaakkola, Jordan and Singh 1994). The first condition lets the steps add up to enough movement to reach the answer from anywhere; the second makes the accumulated noise, a sum of zero-mean terms with variances proportional to $\alpha_k^2$, finite. The proof shows that the iterates track the solutions of the ordinary differential equation $\dot V = D(\mathcal{T}^\pi V - V)$, where $D$ is the diagonal matrix of visit frequencies, and that the contraction property of $\mathcal{T}^\pi$ makes $V^\pi$ a globally stable equilibrium of that ODE. With a constant $\alpha$, TD converges in expectation and then fluctuates around $V^\pi$ with a spread that shrinks with $\alpha$.

Bias and variance. The MC target is unbiased with high variance. The TD target has low variance, since only $R_{t+1}$ and $S_{t+1}$ are random, but is biased by however wrong $V(S_{t+1})$ currently is; the bias shrinks as learning proceeds. TD also exploits the Markov structure: what it learns about $S_{t+1}$ from any episode immediately improves the targets of every state that leads there. On problems that are Markov, TD usually learns faster; the figure's left panel shows it on a 5-state random walk.

A remark on why this matters beyond RL: Schultz, Dayan and Montague (1997) found that the firing of dopamine neurons in monkeys, recorded while they learned to expect juice after a cue, behaves like a TD error: a burst for unexpected reward, a burst moving back to the cue as it becomes predictive, and a dip when an expected reward is withheld.

What batch TD and batch MC converge to

Suppose only a fixed set of episodes is available, and the updates are applied over and over (summing each pass's increments, with a small step) until nothing changes. Both methods converge, but to different answers, and the difference explains a lot.

Batch MC converges to the average of the observed returns from each state: the values that minimise the squared error on the training returns.

Batch TD(0) computes the certainty-equivalence estimate

Let $\hat P(s'\mid s)$ be the fraction of observed transitions from $s$ that went to $s'$, and $\hat r(s)$ the average reward observed on leaving $s$: the maximum-likelihood model of the Markov chain. Batch TD(0) converges to the exact value function of that model,

$$V = \hat r + \gamma\hat PV,\qquad V = (I - \gamma\hat P)^{-1}\hat r .$$

Proof. At a fixed point of batch updating, the summed TD errors from each state are zero. With $N(s)$ transitions from $s$, indexed by $i$,

$$0 = \sum_{i:\,s_i = s}\big(r_i + \gamma V(s'_i) - V(s)\big) = N(s)\Big[\hat r(s) + \gamma\sum_{s'}\hat P(s'\mid s)V(s') - V(s)\Big],$$

which is the Bellman equation of the estimated model. It has a unique solution when $\gamma < 1$, or when every state of the model leads to termination. (That the iteration actually converges to it, for a small enough step, follows because the summed update is $\alpha N(\hat r + \gamma\hat PV - V)$, a linear system whose matrix has eigenvalues with negative real part.) $\square$

Sutton and Barto's example makes the difference vivid. Eight episodes are observed: one goes A, reward 0, then B, reward 0, end; six are B, reward 1, end; one is B, reward 0, end. Batch MC says $V(A) = 0$, because the only return ever observed from A was 0. Batch TD says $V(A) = 0.75$, because A always went to B, and B is worth $\frac68 = 0.75$. If the process is Markov, TD's answer is the better one: it uses the eight episodes' worth of information about B to evaluate A, which MC throws away. The code confirms both numbers, and on the 5-state random walk confirms the theorem exactly: after five episodes, batch TD's values equal the maximum-likelihood model's values to four decimals, with lower error than batch MC's.

$n$-step returns

Between one step and the whole episode lie the $n$-step returns: $n$ real rewards, then bootstrap.

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1}R_{t+n} + \gamma^nV(S_{t+n}),$$

with $G_t^{(n)} = G_t$ if the episode ends before $t + n$. $n = 1$ is TD(0); $n = \infty$ is MC. The $n$-step update $V(S_t)\leftarrow V(S_t) + \alpha(G_t^{(n)} - V(S_t))$ can be made at time $t + n$. Its expected target is $n$ applications of the Bellman operator, $\mathbb{E}[G_t^{(n)}\mid S_t = s] = ((\mathcal{T}^\pi)^nV)(s)$, so by the contraction property

$$\max_s\big|\mathbb{E}[G_t^{(n)}\mid S_t = s] - V^\pi(s)\big|\le\gamma^n\max_s|V(s) - V^\pi(s)|:$$

the error-reduction property. Longer returns shrink the bias inherited from $V$ geometrically, at the cost of more variance from more random steps. The figure's right panel shows the trade-off on a 19-state random walk: averaged over the first 10 episodes, $n = 4$ with $\alpha = 0.4$ gives the lowest error, 0.256, against 0.342 for one-step TD and 0.504 for (essentially) MC. Note also how the best step size shrinks as $n$ grows: longer returns are noisier targets, so each must be trusted less.

Left: error of TD(0) and constant-α MC on the 5-state random walk, averaged over 100 runs (Sutton and Barto's figure 6.2). Right: $n$-step TD on the 19-state walk, error averaged over the first 10 episodes and 100 runs, against the step size (their figure 7.2). From the code.

The $\lambda$-return and eligibility traces

Instead of choosing one $n$, average them all with geometrically decaying weights. The $\lambda$-return, for $\lambda\in[0, 1]$, is

$$G_t^\lambda = (1 - \lambda)\sum_{n=1}^\infty\lambda^{n-1}G_t^{(n)},$$

where the weights $(1 - \lambda)\lambda^{n-1}$ sum to 1, and in an episode that ends at $T$, all the weight from $n = T - t$ onwards, $\lambda^{T-t-1}$, lands on the full return. $\lambda = 0$ gives TD(0) and $\lambda = 1$ gives MC. Updating towards $G_t^\lambda$ is the forward view of TD($\lambda$). It looks into the future, so as written it must wait for the episode to end. The backward view does the same thing incrementally.

Grouping the terms of $G_t^\lambda$ by the first step gives a recursion (exercise 5): $G_t^\lambda = R_{t+1} + \gamma\big[(1 - \lambda)V(S_{t+1}) + \lambda G_{t+1}^\lambda\big]$. Subtract $V(S_t)$ from both sides:

$$G_t^\lambda - V(S_t) = \underbrace{R_{t+1} + \gamma V(S_{t+1}) - V(S_t)}_{\delta_t} + \gamma\lambda\big(G_{t+1}^\lambda - V(S_{t+1})\big) = \sum_{k\ge t}(\gamma\lambda)^{k-t}\delta_k .$$

The $\lambda$-return error is a discounted sum of future TD errors. Now add up the forward-view updates to a state $s$ over an episode, with $V$ held fixed during the episode, and swap the order of summation:

$$\sum_t\alpha\big(G_t^\lambda - V(S_t)\big)\mathbf{1}[S_t = s] = \sum_t\alpha\,\mathbf{1}[S_t = s]\sum_{k\ge t}(\gamma\lambda)^{k-t}\delta_k = \sum_k\alpha\,\delta_k\underbrace{\sum_{t\le k}(\gamma\lambda)^{k-t}\mathbf{1}[S_t = s]}_{z_k(s)} .$$
TD($\lambda$), backward view

Keep an eligibility trace $z(s)$ for every state. At each step, compute $\delta_t$, then

$$z\leftarrow\gamma\lambda z,\quad z(S_t)\leftarrow z(S_t) + 1,\qquad V\leftarrow V + \alpha\,\delta_t\,z .$$

Applied with $V$ fixed during the episode, these updates sum to exactly the forward view's $\lambda$-return updates.

The trace records how recently and how often each state was visited: when a surprise $\delta_t$ arrives, every state is blamed in proportion to its trace. This solves the credit-assignment problem incrementally, with one vector of memory and no need to store the episode. Updating $V$ during the episode, as the code does, makes the equivalence approximate. True online TD($\lambda$) (van Seijen and Sutton, 2014) uses a slightly different "dutch" trace that makes it exact even then. With the plain accumulating trace above, a state revisited many times builds a trace above 1, and large step sizes diverge: the code finds TD(1) blowing up for $\alpha\ge0.15$ on the 19-state walk, where it does worse than MC. On the same walk, TD($\lambda$) with $\lambda = 0.8$ reaches an error of 0.254, the best of all the methods tried, close to the best $n$-step method.

The $\lambda$-return reappears in lesson 38 as generalised advantage estimation (GAE), the standard way modern policy-gradient methods, including PPO, estimate advantages: $\hat A_t = \sum_k(\gamma\lambda)^k\delta_{t+k}$, the same sum of TD errors.

Code from scratch

Part 1 compares TD(0) with constant-α MC on the 5-state random walk, starting from $V = 0.5$, for 100 episodes and 100 runs. Part 2 runs batch MC and batch TD on Sutton and Barto's A/B episodes. Part 3 checks the certainty-equivalence theorem: from five random-walk episodes, it builds the maximum-likelihood model, solves its Bellman equation, and compares the result with batch TD and batch MC. Part 4 runs $n$-step TD on the 19-state walk for seven values of $n$ and 20 step sizes, keeping one value table per step size, and part 5 does the same for TD($\lambda$) with accumulating traces. The code replays each episode after it ends, updating states in order. All $n$ and $\lambda$ see the same 100 × 10 episodes.

import numpy as np

def walk_episode(n, rng):
    """A random walk on states 1..n, started in the middle, stepping left or right with equal
    probability until it leaves at 0 or n + 1. Returns the visited states and the rewards."""
    s, states, rewards = (n + 1) // 2, [], []
    while 1 <= s <= n:
        states.append(s)
        s += rng.choice((-1, 1))
        rewards.append(0.0)
    return states, rewards, s

# ---- Part 1: the 5-state random walk. Reward 1 for leaving on the right, 0 otherwise, gamma = 1.
# The true value of state k is k / 6: the probability of leaving on the right.
n5 = 5
true5 = np.arange(1, n5 + 1) / (n5 + 1)
rms = lambda V, true: np.sqrt(np.mean((V - true) ** 2))

def run5(method, alpha, episodes=100, runs=100):
    """Average RMS error after each episode, over runs. V starts at 0.5 everywhere."""
    err = np.zeros(episodes)
    for r in range(runs):
        rng = np.random.default_rng(r)
        V = np.full(n5 + 2, 0.5); V[0] = V[-1] = 0.0                  # terminal values are 0
        for e in range(episodes):
            states, _, end = walk_episode(n5, rng)
            G = 1.0 if end == n5 + 1 else 0.0
            if method == "MC":                                       # every state's return is G
                for s in states:
                    V[s] += alpha * (G - V[s])
            else:                                                    # TD(0): bootstrap from V(s')
                for s, s2 in zip(states, states[1:] + [end]):
                    r_ = 1.0 if s2 == n5 + 1 else 0.0
                    V[s] += alpha * (r_ + V[s2] - V[s])
            err[e] += rms(V[1:-1], true5)
    return err / runs

curves5 = {}
for method, alphas in [("TD", [0.05, 0.1, 0.15]), ("MC", [0.01, 0.02, 0.03, 0.04])]:
    for a in alphas:
        curves5[(method, a)] = run5(method, a)
        c = curves5[(method, a)]
        print(f"5-state walk, {method} alpha = {a:.2f}: RMS error after 10, 50, 100 episodes:"
              f" {c[9]:.3f} {c[49]:.3f} {c[99]:.3f}")

# ---- Part 2: batch updating. Sutton and Barto's example 6.4: eight episodes,
# A,0,B,0 once; B,1 six times; B,0 once. Replay them until the estimates stop changing.
episodes = [[("A", 0, "B"), ("B", 0, None)]] + [[("B", 1, None)]] * 6 + [[("B", 0, None)]]
def batch(method, alpha=0.01, sweeps=20_000):
    V = {"A": 0.0, "B": 0.0, None: 0.0}
    for _ in range(sweeps):
        inc = {"A": 0.0, "B": 0.0}
        for ep in episodes:
            G = 0.0
            for s, r, s2 in reversed(ep):
                G += r
                target = G if method == "MC" else r + V[s2]
                inc[s] += target - V[s]
        for s in inc:                                                # one step per pass over the data
            V[s] += alpha * inc[s]
    return V["A"], V["B"]
print("batch MC: V(A) = %.4f, V(B) = %.4f;  batch TD: V(A) = %.4f, V(B) = %.4f" % (*batch("MC"), *batch("TD")))

# ---- Part 3: batch TD is the value of the maximum-likelihood model ("certainty equivalence").
rng = np.random.default_rng(7)
data = [walk_episode(n5, rng) for _ in range(5)]
counts = np.zeros((n5 + 2, n5 + 2)); rew = np.zeros(n5 + 2)
for states, _, end in data:
    for s, s2 in zip(states, states[1:] + [end]):
        counts[s, s2] += 1; rew[s] += 1.0 if s2 == n5 + 1 else 0.0
visited = counts.sum(1) > 0
P_hat = np.where(visited[:, None], counts / np.maximum(counts.sum(1, keepdims=True), 1), 0)
r_hat = np.where(visited, rew / np.maximum(counts.sum(1), 1), 0)
idx = np.flatnonzero(visited)
V_ce = np.zeros(n5 + 2)
V_ce[idx] = np.linalg.solve(np.eye(len(idx)) - P_hat[np.ix_(idx, idx)], r_hat[idx])
V = np.zeros(n5 + 2)
for _ in range(20_000):
    inc = np.zeros(n5 + 2)
    for states, _, end in data:
        for s, s2 in zip(states, states[1:] + [end]):
            inc[s] += (1.0 if s2 == n5 + 1 else 0.0) + V[s2] - V[s]
    V += 0.01 * inc
G_mc = np.zeros(n5 + 2); N_mc = np.zeros(n5 + 2)
for states, _, end in data:
    for s in states:
        G_mc[s] += 1.0 if end == n5 + 1 else 0.0; N_mc[s] += 1
print("5 episodes; visits per state:", N_mc[1:-1].astype(int).tolist())
print("batch TD:              ", np.round(V[1:-1], 4))
print("max-likelihood model:  ", np.round(V_ce[1:-1], 4))
print("batch MC (mean return):", np.round(G_mc[1:-1] / np.maximum(N_mc[1:-1], 1), 4))
print(f"RMS error: batch TD {rms(V[1:-1], true5):.3f}, batch MC {rms(G_mc[1:-1] / np.maximum(N_mc[1:-1], 1), true5):.3f}")

# ---- Part 4: n-step TD on the 19-state random walk (rewards -1 on the left, +1 on the right).
# Error averaged over the first 10 episodes and over states, for a grid of step sizes.
n19 = 19
true19 = np.arange(-(n19 - 1), n19, 2) / (n19 + 1)                 # -0.9, -0.8, ..., 0.9
alphas = np.linspace(0, 1, 21)[1:]
ns_ = [1, 2, 4, 8, 16, 32, 512]
nstep_err = {}
runs = 100
eps_all = []
for r in range(runs):                                               # the same episodes for every n and alpha
    rng = np.random.default_rng(1000 + r)
    eps_all.append([walk_episode(n19, rng) for _ in range(10)])
for nn in ns_:
    total = np.zeros(len(alphas))
    for r in range(runs):
        V = np.zeros((len(alphas), n19 + 2))                        # one value table per alpha
        for states, _, end in eps_all[r]:
            path = states + [end]
            Rw = [0.0] * (len(states) - 1) + [1.0 if end == n19 + 1 else -1.0]
            T = len(states)
            for t in range(T):
                h = min(t + nn, T)                                  # the n-step return from t
                G = sum(Rw[t:h])                                    # gamma = 1
                if h < T:
                    G = G + V[:, path[h]]
                s = path[t]
                V[:, s] += alphas * (G - V[:, s])
            total += np.sqrt(np.mean((V[:, 1:-1] - true19) ** 2, axis=1))
    nstep_err[nn] = total / (runs * 10)
    b = np.argmin(nstep_err[nn])
    print(f"19-state walk, n = {nn:3d}: best alpha {alphas[b]:.2f}, average RMS error over 10 episodes {nstep_err[nn][b]:.3f}")

# ---- Part 5: TD(lambda) with accumulating eligibility traces, online, on the same episodes.
lam_err = {}
np.seterr(over="ignore", invalid="ignore")                        # large alpha with long traces diverges
for lam in [0.0, 0.4, 0.8, 0.9, 0.95, 1.0]:
    total = np.zeros(len(alphas))
    for r in range(runs):
        V = np.zeros((len(alphas), n19 + 2))
        for states, _, end in eps_all[r]:
            z = np.zeros(n19 + 2)                                   # the eligibility trace
            for s, s2 in zip(states, states[1:] + [end]):
                rw = 0.0 if 1 <= s2 <= n19 else (1.0 if s2 == n19 + 1 else -1.0)
                delta = rw + V[:, s2] - V[:, s]                     # TD error, one per alpha
                z *= lam; z[s] += 1                                 # decay all traces, bump this state
                V += (alphas * delta)[:, None] * z[None, :]
            total += np.sqrt(np.mean((V[:, 1:-1] - true19) ** 2, axis=1))
    err = total / (runs * 10)
    ok = np.isfinite(err) & (err < 10)
    lam_err[lam] = np.where(ok, err, np.nan)
    b = np.nanargmin(lam_err[lam])
    print(f"19-state walk, TD(lambda = {lam:.2f}): best alpha {alphas[b]:.2f}, average RMS error {lam_err[lam][b]:.3f};"
          f" diverges for alpha >= {alphas[~ok][0]:.2f}" if (~ok).any() else
          f"19-state walk, TD(lambda = {lam:.2f}): best alpha {alphas[b]:.2f}, average RMS error {lam_err[lam][b]:.3f}")

Reading the output. On the 5-state walk, TD with $\alpha = 0.05$ reaches an RMS error of 0.036 after 100 episodes; the best MC run is at 0.076. A larger $\alpha$ learns faster at first (TD at 0.15 is best after 10 episodes) and then plateaus higher, the familiar step-size trade-off. The A/B example gives exactly 0 and 0.75 for $V(A)$. On five random-walk episodes, batch TD and the maximum-likelihood model agree to every printed digit, as the theorem says; batch MC disagrees because it uses only the returns that happened to follow each state. In parts 4 and 5, intermediate settings win: $n = 4$ (0.256) and $\lambda = 0.8$ (0.254), against 0.342 for one-step TD and 0.50–0.62 for the Monte Carlo ends of both families.

Exercises

  1. A single non-terminal state loops to itself with probability $p$ and ends with probability $1 - p$, with reward 1 on every step and $\gamma = 1$. From one episode of length $L$, what are the first-visit and every-visit MC estimates of $V$? Show the first is unbiased and the second is not, and find $V$.
  2. Show that the constant-$\alpha$ MC estimate after $N$ returns is $(1 - \alpha)^NV_0 + \sum_{i=1}^N\alpha(1 - \alpha)^{N-i}G_i$. What is its variance if the $G_i$ are independent with variance $\sigma^2$, as $N\to\infty$?
  3. Four episodes on states A and B (rewards after each arrow, $\gamma = 1$): A →0 B →1 end; A →0 B →0 end; B →1 end; B →1 end. Compute the batch MC and batch TD estimates of $V(A)$ and $V(B)$.
  4. Prove the error-reduction property of $n$-step returns from the contraction property.
  5. Prove the recursion $G_t^\lambda = R_{t+1} + \gamma[(1 - \lambda)V(S_{t+1}) + \lambda G_{t+1}^\lambda]$ from the definition.
  6. With $\lambda = 1$ and $\gamma = 1$, show that the summed backward-view updates over an episode equal the every-visit MC updates. What does a "replacing" trace, $z(S_t)\leftarrow1$ instead of $z(S_t)\leftarrow z(S_t) + 1$, give instead?
Answers

1. The episode visits the state $L$ times, with returns $L, L - 1, \dots, 1$. First-visit: $L$. Every-visit: the average, $(L + 1)/2$. $L$ is geometric with $\mathbb{E}L = 1/(1 - p)$, and $V = \mathbb{E}L = 1/(1 - p)$, so first-visit is unbiased. Every-visit has expectation $(\mathbb{E}L + 1)/2 = \frac{2 - p}{2(1 - p)}\ne V$ for $p > 0$. (Over many episodes, every-visit averages over all visits, which weights long episodes more, and it becomes consistent.)

2. Unroll $V_N = (1 - \alpha)V_{N-1} + \alpha G_N$. The variance is $\sum_i\alpha^2(1 - \alpha)^{2(N-i)}\sigma^2\to\frac{\alpha^2\sigma^2}{1 - (1 - \alpha)^2} = \frac{\alpha\sigma^2}{2 - \alpha}$: it never goes to zero, which is the price of tracking.

3. MC: returns from A are 1 and 0, so $V(A) = 0.5$; returns from B are 1, 0, 1, 1, so $V(B) = 0.75$. TD: B is worth its average reward, 0.75; A always moves to B with reward 0, so $V(A) = 0.75$.

4. $\mathbb{E}[G_t^{(n)}\mid S_t = s] = ((\mathcal{T}^\pi)^nV)(s)$ by conditioning on the first step and induction. Since $V^\pi = (\mathcal{T}^\pi)^nV^\pi$, the left side of the property is $\|(\mathcal{T}^\pi)^nV - (\mathcal{T}^\pi)^nV^\pi\|_\infty\le\gamma^n\|V - V^\pi\|_\infty$.

5. $G_t^{(n)} = R_{t+1} + \gamma G_{t+1}^{(n-1)}$ for $n\ge2$ and $G_t^{(1)} = R_{t+1} + \gamma V(S_{t+1})$. So $G_t^\lambda = (1 - \lambda)G_t^{(1)} + (1 - \lambda)\sum_{n\ge2}\lambda^{n-1}(R_{t+1} + \gamma G_{t+1}^{(n-1)}) = R_{t+1} + \gamma(1 - \lambda)V(S_{t+1}) + \gamma\lambda(1 - \lambda)\sum_{m\ge1}\lambda^{m-1}G_{t+1}^{(m)}$, using that the weights sum to 1 to collect the $R_{t+1}$ terms. The last sum is $\gamma\lambda G_{t+1}^\lambda$.

6. With $\gamma\lambda = 1$, $G_t^\lambda - V(S_t) = \sum_{k\ge t}\delta_k = G_t - V(S_t)$ (the sum telescopes, and the terminal value is 0), so the forward view is MC with the full return, and the derivation in the text shows the backward view equals it, with one update per visit: every-visit MC. A replacing trace caps the trace at 1. With $\gamma\lambda = 1$ it never decays, so $z_k(s) = 1$ for every step $k$ from the first visit to $s$ on, and the summed update is $\alpha\sum_{k\ge t_1}\delta_k = \alpha(G_{t_1} - V(s))$, with $t_1$ the first visit: exactly first-visit MC. It also avoids the trace growth that made accumulating traces diverge.
