Linear models from scratch

Implement least squares, gradient descent, logistic regression, ridge, the lasso and cross-validation in plain NumPy, then use them to answer a few questions about real behaviour. An autograder checks every function and tells you what is wrong. Expect three to five hours.

Builds on: 01, 02, 03, 04, 05Files: assignments/A1-linear-models

Set-up

You need Python 3 and NumPy, nothing else. From the repository root:

cd subjects/machine-learning/assignments/A1-linear-models
cp starter.py mine.py          # work in your own copy
python3 check.py mine.py       # run as often as you like

The checker prints PASS, FAIL with a reason and a hint, or todo for each function. It doesn't compare your numbers with a hidden answer key. It checks properties the correct answer must have: the normal equations, the KKT conditions of the lasso, the gradient being zero at the logistic-regression solution, invariance to shifting $y$. So a pass means your function really is correct, and a failure message tells you which property you broke.

Rules

Use NumPy only (no scikit-learn). Don't form $(X^\top X)^{-1}$ explicitly; use np.linalg.solve or lstsq. Read the docstring of each function before starting it: they pin down conventions such as the $\tfrac1{2n}$ in the losses.

Experiments and write-up

Once all twelve checks pass, use your own functions to answer these. Write a short paragraph and include a plot or a table for each. They are the part that makes the ideas stick.

  1. The stability edge. Generate $X$ with two features of very different scales (standard deviations 1 and 10). Run gd_least_squares at 0.5, 0.9, 0.99 and 1.01 times max_stable_lr and plot the loss curves on a log scale. Then standardise the features and repeat. How many steps does each version need to get within $10^{-6}$ of the optimum? Relate the answer to the condition number (lesson 02).
  2. Bias and variance by simulation. Reproduce lesson 04's right-hand figure for ridge instead of polynomial degree: fix a degree-12 polynomial and vary $\lambda$ over a log grid. Plot bias², variance and their sum against $\log\lambda$, and mark the $\lambda$ chosen by choose_lambda on one sample. Is it near the minimum of the true curve?
  3. Degrees of freedom. For the same problem, plot training MSE against ridge_df. Overlay $\sigma^2(1 - \mathrm{df}/n)$. Problem 2 of problem set P2 says when they should agree; do they?
  4. Lasso paths. On data with 20 features of which 3 matter, compute the lasso path over 50 values of $\lambda$ from $\lambda_{\max}$ down to $\lambda_{\max}/1000$, warm-starting each fit from the previous one. In what order do features enter? Make two of the irrelevant features highly correlated with a relevant one and repeat. What changes?
  5. Separable data. Make a linearly separable 2D dataset and run fit_logistic with $\lambda = 0$ for 100, 1,000 and 10,000 steps. Report $\lVert\mathbf{w}\rVert$ and the direction $\mathbf{w}/\lVert\mathbf{w}\rVert$ each time. Explain what you see using lesson 03, then add $\lambda = 0.01$ and explain again.

Grading yourself

Twelve checker passes are worth 60%. Each experiment is worth 8%: full marks if the plot is right and the explanation cites the formula that predicts it. Experiments 1 and 3 have exact theoretical answers, so check your numbers against the theory. When you are done, compare your fit_lasso with sklearn.linear_model.Lasso(alpha=lam) on the same data; they minimise the same objective and should agree to several decimals.
