Assignment A3 · after lessons 09–11

Gradient-boosted trees from scratch

Build a small XGBoost in plain NumPy: the losses and their derivatives, the exact split search, second-order trees, boosting with shrinkage and row subsampling, early stopping and permutation importance. Then use it to find out which knobs matter and when boosting beats a random forest. An autograder checks every function. Expect four to six hours.

Builds on: 09, 10, 11Files: assignments/A3-gradient-boosting

Set-up

You need Python 3 and NumPy. From the repository root:

cd subjects/machine-learning/assignments/A3-gradient-boosting
cp starter.py mine.py          # work in your own copy
python3 check.py mine.py       # run as often as you like

As in A1, the checker prints PASS, FAIL with a reason and a hint, or todo. It checks properties rather than a hidden answer key. Derivatives are compared with finite differences. Your split search is compared with a brute-force search over every threshold. Your trees' leaves must equal $-G/(H + \lambda)$ for the points that land in them, and a depth-1 tree must achieve the best gain over all features. Boosting is checked by replaying each round.

Rules

Use NumPy only. Any tree representation is fine (the lesson uses nested tuples) as long as predict_tree reads it. best_split must be $O(n\log n)$: the checker times it on 200,000 points. The checker runs with floating-point warnings turned into errors, so an overflow in your sigmoid is a failure, not a warning.

The starter also has make_data(n, seed=...), which draws lesson 10's problem: ten features, a label that depends on $x_0^2 + x_1^2 + x_2x_3$, and a best possible test accuracy of about 0.885 (log-loss 0.27).

Experiments and write-up

Once all nine checks pass, use your own code to answer these. Write a short paragraph and include a plot or a table for each. Use three separate draws of make_data for training (1,000 points), validation (1,000) and test (4,000), and choose every setting on validation only.

  1. Learning rate against rounds. Train with $\nu = 1, 0.3, 0.1, 0.03$ (depth 3), with enough rounds for each to pass its best validation loss, and use best_rounds to stop. Plot the validation curves on a log $x$-axis, and tabulate the best round, the validation loss and the test loss. How does the best round scale with $\nu$? Is a smaller $\nu$ always better, and what does it cost? (For reference, our solution reaches test log-loss between 0.43 and 0.47 for all four rates, with $\nu = 1$ stopping after about 15 trees.) Relate what you see to problem 17 of problem set P3.
  2. Depth is interaction order. Write a generator whose label depends on $x_0x_1x_2$ (a three-way interaction) and nothing else. Fit depths 1 to 4, each with early stopping. Which depth is the first to do clearly better than chance, and why? Repeat on make_data, whose strongest interaction is two-way.
  3. Boosting against a forest. Using lesson 10's code for the forest (100 trees, $m = 3$) and your booster (tuned on validation), compare test accuracy and log-loss for training sets of 300, 1,000 and 3,000 points. For the forest, use the vote fraction, clipped to $[0.01, 0.99]$, as the probability. Then compute each model's ECE (lesson 08). Which model ranks better, and which is better calibrated? Why would the forest's vote fractions be poorly calibrated?
  4. Importance with correlated features. Compute permutation importances of your tuned booster on the test set. Then add a feature that is $x_0$ plus a little noise ($\sigma = 0.05$), refit and recompute. What happens to the importance of $x_0$, and why? What does this mean for reading importance scores as "what the model relies on"?
  5. Which knob matters? Starting from your best depth-3 model, vary one setting at a time: $\lambda\in\{0, 1, 10\}$, $\gamma\in\{0, 0.5, 2\}$, min_child_weight $\in\{0, 1, 5\}$ and subsample $\in\{1, 0.7, 0.5\}$ (average three seeds for the last). Rank them by how much they change the best validation loss, and explain the top one using lesson 11.
