Assignment A4 · after lessons 12–14

An autograd engine and an MLP on MNIST

Turn lesson 13's scalar engine into a small tensor library: arrays that remember how they were computed, broadcasting-aware gradients, a fused softmax cross-entropy, linear layers, dropout, SGD with momentum and AdamW. Then train a multilayer perceptron on MNIST's 60,000 handwritten digits to better than 98% test accuracy, with nothing but NumPy and your own code. An autograder checks every part. Expect six to eight hours.

Builds on: 07, 12, 13, 14Files: assignments/A4-autograd-mlp

Set-up

You need Python 3 and NumPy. From the repository root:

cd subjects/machine-learning/assignments/A4-autograd-mlp
cp starter.py mine.py          # work in your own copy
python3 check.py mine.py       # run as often as you like

The checker compares every gradient your engine computes with central finite differences, on tensors of awkward shapes, including broadcasting. It checks the optimisers against properties their update rules must have (Adam's first step has size exactly the learning rate in every coordinate; decoupled weight decay shrinks a parameter with zero gradient by exactly $1 - \eta\lambda$). Then it trains a small network end to end. Floating-point warnings are errors, so an overflow in your cross-entropy is a failure.

The design

A Tensor holds data (a NumPy array), grad, its parent tensors, and a _backward closure that adds its gradient, times the local derivative, into each parent's grad. Addition is written for you as the worked example of the pattern. Every other operation follows it. The table in lesson 13 lists the backward rule for each.

The starter also provides load_mnist(), which downloads the dataset once (about 11 MB) to ~/.cache/learn-mnist and returns images as rows of 784 numbers in $[0, 1]$, and evaluate(model, X, y), which switches dropout off and returns the accuracy.

Experiments and write-up

Once all twelve checks pass, write a training script that uses your library. Hold out the last 10,000 training images as a validation set and make every choice on it; touch the test set once, at the end. Write a short paragraph and include a plot or a table for each experiment.

  1. A baseline. Train $784\to256\to256\to10$ with AdamW (learning rate $10^{-3}$, batch 128) for 5 epochs. Plot training loss per step and validation accuracy per epoch. Our solution reaches about 97.5% validation accuracy, at about 4 seconds per epoch on a laptop CPU. Then check lesson 14's recipe on your own code: is the loss at step 0 close to $\log10$? Can you drive the loss on a single batch of 32 to nearly 0?
  2. Initialisation. Make the network 10 hidden layers deep (width 256) and train it with He initialisation, with weights $\mathcal{N}(0, 1/\text{fan-in})$, and with $\mathcal{N}(0, 0.01^2)$, using SGD with momentum 0.9 so that Adam's rescaling doesn't hide the problem. Record the gradient norm of the first layer at step 0 and the validation accuracy after one epoch. Relate the results to lesson 14's variance recursion.
  3. Optimisers. Compare SGD (with and without momentum) and AdamW, each with the best learning rate from a sweep over factors of 3. Plot the validation curves. Which is fastest in the first epoch, and which ends best after 15 epochs with a cosine learning-rate schedule?
  4. Regularisation and the 98% target. Train $784\to512\to512\to10$ for 15 epochs with AdamW, weight decay 0.01 and a cosine schedule, with dropout 0 and 0.2. Compare the gap between training and validation accuracy. Report the test accuracy of your final choice: it should be above 98% (our solution gets 98.5% without dropout and 98.6% with it).
  5. Look at the mistakes. Show 20 test images your best model gets wrong, with the predicted and true labels and the predicted probability. Are the errors ones a person would make? Plot a reliability diagram (lesson 08) of the test predictions: is the network overconfident?

Grading yourself

Twelve checker passes are worth 50%. Each experiment is worth 10%: full marks if the plot or table is right and the explanation names the mechanism behind it. If PyTorch is installed, rebuild the experiment 4 network with torch.nn and the same settings: its accuracy should be within a few tenths of a percent of yours, and it will be several times faster.
