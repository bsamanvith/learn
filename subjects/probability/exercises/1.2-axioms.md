### 1.2.1 🟢 Three numbers
$P(A) = 0.3$, $P(B) = 0.5$, $P(A \cap B) = 0.1$. Find **(a)** $P(A \cup B)$, **(b)** $P(A^c \cap B)$, **(c)** $P(A^c \cap B^c)$.

### 1.2.2 🟢 Valid or not?
Which of these are valid probability assignments on $\Omega = \{a, b, c\}$? Say which axiom fails for the others.
**(a)** $0.5, 0.3, 0.2$  **(b)** $0.6, 0.6, -0.2$  **(c)** $0.4, 0.4, 0.4$  **(d)** $1, 0, 0$

### 1.2.3 🟢 Too big to be disjoint
Can two disjoint events have $P(A) = 0.6$ and $P(B) = 0.5$? Explain with an axiom.

### 1.2.4 🟢 A loaded die
A die is weighted so that $P(k) = ck$ for $k = 1, \dots, 6$. Find $c$, $P(\text{even})$ and $P(\text{at most } 2)$.

### 1.2.5 🟡 How much overlap?
$P(A) = 0.7$ and $P(B) = 0.5$. Find the smallest and largest possible values of **(a)** $P(A \cap B)$ and **(b)** $P(A \cup B)$.
Describe (or draw) a situation achieving each extreme.

### 1.2.6 🟡 Exactly one
Prove $P(A \triangle B) = P(A) + P(B) - 2P(A \cap B)$.

### 1.2.7 🟡 Waiting for heads
With $P(\text{first head on flip } n) = 2^{-n}$, find **(a)** $P(\text{first head after flip 3})$, **(b)** $P(\text{first head on a multiple of 3})$.

### 1.2.8 🟡 Survey
In a town, 60% read the news, 45% listen to podcasts, and 25% do both. What fraction do **(a)** neither, **(b)** exactly one?

### 1.2.9 🟡 Union bound in engineering
A machine has 20 parts. Each fails during a year with probability 0.001, and you know nothing about how failures are related.
**(a)** Give an upper bound on $P(\text{some part fails})$. **(b)** If the failures were independent, the exact answer would be $1 - 0.999^{20}$. How good was the bound?

### 1.2.10 🔴 No random integer, revisited
Show there's no probability on $\Omega = \{1, 2, 3, \dots\}$ with $P(\{n\}) = P(\{m\})$ for all $n, m$.
Then show that $P(\{n\}) = \frac{6}{\pi^2 n^2}$ **is** a valid probability. (You may use $\sum 1/n^2 = \pi^2/6$.) Under it, is "even" more or less likely than "odd"?

### 1.2.11 🔴 Ten claims
A report makes 10 claims. Each is true with probability at least 0.99, and nothing is known about how they're related.
**(a)** What can you guarantee about $P(\text{all 10 true})$? **(b)** How many such claims can a report make before the guarantee drops below 50%?

### 1.2.12 🟣 Finite from countable
Starting from the three axioms only, prove $P(\emptyset) = 0$ and then finite additivity. (Redo the chapter's proofs without looking.)

### 1.2.13 🟣 Shrinking events
Use Theorem 8 (continuity for growing events) to prove: if $B_1 \supseteq B_2 \supseteq \cdots$, then $P\left(\bigcap_n B_n\right) = \lim_n P(B_n)$.
Apply it to show $P(\text{all flips are heads, forever}) = 0$.

### 1.2.14 🔁 Same answer twice *(callback to 1.1)*
In Exercise 1.1.5 you found $P(H_1 \triangle T_3) = 1/2$ for three coin flips by listing outcomes. Get it again from 1.2.6's formula.

### 1.2.15 💻 π from darts
A dart is uniform on the unit square. The quarter-disc $x^2 + y^2 \le 1$ has area $\pi/4$, so $P(\text{dart in quarter-disc}) = \pi/4$.
Estimate π with $N = 10^3, 10^4, 10^5, 10^6$ darts. How does the error shrink?

<details><summary>1.2.3</summary>

</details>

<details><summary>1.2.4</summary>

$c(1 + 2 + \cdots + 6) = 21c = 1$, so $c = 1/21$.
$P(\text{even}) = (2 + 4 + 6)/21 = 12/21 = 4/7$. $P(\text{at most } 2) = 3/21 = 1/7$.
</details>

<details><summary>1.2.5</summary>

**(a)** Largest: $P(A \cap B) \le \min(P(A), P(B)) = 0.5$, reached when $B \subseteq A$.
Smallest: Bonferroni gives $P(A \cap B) \ge 0.7 + 0.5 - 1 = 0.2$, reached when $A \cup B = \Omega$, so that $A$ and $B$ together cover everything.

**(b)** $P(A \cup B) = 1.2 - P(A \cap B)$, so it ranges from $1.2 - 0.5 = 0.7$ (when $B \subseteq A$) up to $1.2 - 0.2 = 1$ (when they cover $\Omega$).

In the widget: put B inside A for one extreme, and spread them as far apart as possible for the other.
</details>

<details><summary>1.2.6</summary>

$A \triangle B = (A \setminus B) \cup (B \setminus A)$, a disjoint union. Also $P(A \setminus B) = P(A) - P(A \cap B)$ and $P(B \setminus A) = P(B) - P(A \cap B)$.
Adding: $P(A \triangle B) = P(A) + P(B) - 2P(A \cap B)$. ∎

(Compare the indicator identity in 1.1.6. The same formula holds one level up.)
</details>

<details><summary>1.2.7</summary>

**(b)** $\sum_{k \ge 1} 2^{-3k} = \frac{1/8}{1 - 1/8} = \frac17$.
</details>

<details><summary>1.2.9</summary>

**(a)** Union bound: $\le 20 \times 0.001 = 0.02$.
**(b)** $1 - 0.999^{20} \approx 0.01981$. The bound is off by about 1%, in relative terms.

For rare events, the union bound is nearly exact, because overlaps (two parts failing) are much rarer still. It gets bad when the sum approaches or exceeds 1.
</details>

<details><summary>1.2.10</summary>

**No uniform:** if $P(\{n\}) = c$ for all $n$, countable additivity gives $1 = \sum_n c$. That sum is $0$ if $c = 0$ and $+\infty$ if $c > 0$. Contradiction.

**$6/(\pi^2 n^2)$:** each value is $\ge 0$, and $\sum_n \frac{6}{\pi^2 n^2} = \frac{6}{\pi^2} \cdot \frac{\pi^2}{6} = 1$. ✓

**Even vs odd:** $P(\text{even}) = \sum_k \frac{6}{\pi^2 (2k)^2} = \frac14 \cdot 1 = \frac14$. So $P(\text{odd}) = \frac34$. Odd is three times as likely, because small numbers carry most of the weight and 1 alone has $6/\pi^2 \approx 0.61$.
</details>

<details><summary>1.2.11</summary>

**(a)** Bonferroni: $P(\text{all true}) \ge 1 - \sum P(\text{claim } i \text{ false}) \ge 1 - 10(0.01) = 0.90$.
**(b)** $1 - 0.01n \ge 0.5$ requires $n \le 50$. With 51 or more claims at 99% each, nothing (from this bound) stops the whole report being wrong more often than not.

The moral for long arguments: every step at 99% reliability, over 100 steps, guarantees nothing.
</details>

<details><summary>1.2.12</summary>

See Theorems 1 and 2 in §7. The key ideas: (i) write $\Omega = \Omega \cup \emptyset \cup \emptyset \cup \cdots$ and use non-negativity to force $P(\emptyset) = 0$;
(ii) pad a finite list of disjoint events with infinitely many $\emptyset$'s, so countable additivity applies.
</details>

<details><summary>1.2.13</summary>

The complements grow: $B_1^c \subseteq B_2^c \subseteq \cdots$. Theorem 8 gives $P\left(\bigcup B_n^c\right) = \lim P(B_n^c)$.
By De Morgan, $\bigcup B_n^c = \left(\bigcap B_n\right)^c$. So $1 - P\left(\bigcap B_n\right) = \lim (1 - P(B_n))$, which gives $P\left(\bigcap B_n\right) = \lim P(B_n)$. ∎

**All heads forever:** let $B_n$ = "the first $n$ flips are heads". These shrink, $P(B_n) = 2^{-n} \to 0$, and $\bigcap B_n$ = "all heads forever".
So it has probability $0$, even though it's a perfectly possible outcome (see the "probability 0 ≠ impossible" pitfall).
</details>

<details><summary>1.2.14</summary>

$P(H_1) = \frac12$, $P(T_3) = \frac12$, $P(H_1 \cap T_3) = \frac14$. So $P(H_1 \triangle T_3) = \frac12 + \frac12 - 2 \cdot \frac14 = \frac12$. ✓ Same answer, no listing needed.
</details>

<details><summary>1.2.15</summary>

```python
import random, math
for N in (10**3, 10**4, 10**5, 10**6):
    inside = sum(random.random()**2 + random.random()**2 <= 1 for _ in range(N))
    est = 4 * inside / N
    print(N, est, abs(est - math.pi))
```

Typical errors are around 0.05, 0.016, 0.005 and 0.0016, shrinking by about $\sqrt{10} \approx 3.2$ for each tenfold increase in $N$. That's the $1/\sqrt N$ law again.
(Precisely: the error in $\pi$ is $4 \times$ the error in a probability near $0.785$, so it's about $4\sqrt{0.785 \cdot 0.215/N} \approx 1.64/\sqrt N$.)

Monte Carlo is a terrible way to compute π, and a wonderful way to compute things nobody has a formula for.
</details>
